# Sketch 001: Announcement Action Icons

## Design Question

哪个现有图标最能表达“查看已读/未读用户”？

## How to View

打开 `.planning/sketches/001-announcement-action-icons/index.html`，或使用本地静态服务访问。

## Variants

- **Users（推荐）** — 强调查看具体用户明细。
- **Chart Bar / Chart** — 两种柱状图，强调阅读数据统计。
- **Check Circle** — 强调已读状态，但可能被误解为启用或审核通过。
- **Clipboard / Document** — 强调阅读记录，但语义相对间接。

## What to Look For

只比较阅读状态图标本身。点击候选项可查看语义说明。
