# Sketch 001: Announcement Action Icons

## Design Question

在眼睛图标改为“预览公告”后，哪个现有图标最能表达“查看已读/未读用户”？

## How to View

打开 `.planning/sketches/001-announcement-action-icons/index.html`，或使用本地静态服务访问。

## Variants

- **A: Users（推荐）** — 强调查看具体用户明细。
- **B: Chart Bar** — 强调阅读数据统计。
- **C: Check Circle** — 强调已读状态，但可能被误解为启用或审核通过。

## What to Look For

比较图标在真实操作列中的辨识度；将鼠标悬停查看提示，并点击眼睛或候选图标体验对应弹窗。
